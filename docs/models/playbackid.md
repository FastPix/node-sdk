# PlaybackId

A collection of Playback ID objects utilized for crafting HLS playback urls.

## Example Usage

```typescript
import { PlaybackId } from "@fastpix/fastpix-node/models";

let value: PlaybackId = {
  id: "your-playback-id",
};
```
